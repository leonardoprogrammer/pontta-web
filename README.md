# Pontta Web

Front-end em Angular para o cadastro de clientes.

## Pré-requisitos

- Node.js e npm
- A API ([pontta-api](https://github.com/leonardoprogrammer/pontta-api)) rodando em `http://localhost:8080/api`

## Como rodar

```bash
npm install
npm start
```

A aplicação sobe em `http://localhost:4200`.
